# Security Policy

This repository is at the design-foundation stage. There is no deployed service or supported production release. Security controls described in the architecture are requirements, not verified capabilities.

Do not submit credentials, personal health information, real calendar contents, or exploit details in public issues. If GitHub private vulnerability reporting is available, use the repository Security tab. Otherwise open a non-sensitive issue asking the maintainer to establish a private reporting channel before sharing details.

Public examples and tests use synthetic data. Future implementations must enforce user ownership, least-privilege integration permissions, credential protection, bounded execution, sensitive-log filtering, and documented export/deletion behavior.

No regulatory certification, clinical validation, or compliance status is claimed.
